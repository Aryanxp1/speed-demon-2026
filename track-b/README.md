The active implementation returns to our Rust engine from `4a879b9`. Selected scan ideas from the user-supplied `Downloads/trackb/trackb` snapshot are adapted into that engine; the supplied file is not substituted wholesale. Its reported 75.365 score is not a result for this submission.

The new dictionary stores exact words of at most twelve bytes beside their IDs in 16-byte entries, probing two entries with AVX2. Longer words use an eight-byte prefix and an index into full 32-byte keys; a matching prefix or CRC never substitutes for equality. The table owns a huge-page-advised mapping and releases it after the corpus scan. Query parsing inserts directly into this table, avoiding a second build and full-key storage for short words. Decimal output uses a digit loop. The original parser, posting streams, phrase evaluation, Boolean operations and guarded worker pool remain.
